## 🤝 Contribution Guide
Thank you for your interest in contributing to **reconi3e_me_sdet-lab**.

### 🧩 How to Contribute
1. Fork the repository  
2. Create a new branch  
3. Make your changes  
4. Submit a pull request with a clear description  

### 📌 Contribution Rules
- Follow clean code principles  
- Use meaningful commit messages  
- Keep folder structure consistent  
- Add comments where needed  
- Ensure tests pass before submitting  

### 🧪 Testing Requirements
- All UI tests must run via TestNG  
- All API tests must run via REST Assured  
- CI pipelines must pass before merge  

### 📄 Code Style
- Java: follow standard conventions  
- Use Page Object Model for UI tests  
- Keep test data externalized
